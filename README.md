# 1. DevOps Fundamentals and Prerequisites
## 1.1 What is DevOps?
1.	It is a culture and practice that improves or increases the company’s ability to deliver the application. 
2.	Improving delivery (Automation, Quality, Monitoring, Testing)
3.	DevOps is a process of improving the application delivery with automation, quality, continuous monitoring & continuous delivery.
## 1.2 Why DevOps?
1.	Back then all the process were manual such as:
System Administrator 	-> creates 	-> server
Build & Release Eng.		-> releases	->app /deploy
Server Admin
2.	Now all above processes are handled by DevOps Eng. For faster app delivery.
3.	App (developer)	-> Deployment (DevOps)	-> Production (Customer)
## 1.3 SDLC (Software Development Life Cycle)
1.	Planning: User requirements
2.	Defining: Documents
3.	Designing: Low-level, High-Level
4.	Building: Developing
5.	Testing: QA, server test
6.	Deploy: Production, Customer
 
## 1.4. Prerequisites
### Roles in a company
1.	Business Analyst 		-> Gathers end user requirements
2.	Product Manager		-> Defines vision, goals & priorities
3.	Product Owner 		-> Manages backlog & makes action plan
4.	Solution/Software Architect 	-> Design technical system structure/frameworks
5.	Developers			-> Build the actual product (UI, APIs, DBs)
6.	QA Engineers			-> Test product quality & performance
7.	DBA				-> Designs & manages the database
8.	DevOps Engineer		-> Builds CI/CD pipelines & manages environments
9.	Release Managers (Opt.)	-> Plans & manages releases
10.	SRE				->Ensures uptime performance, reliability, post-release
11.	Technical Writers		-> Creates documentation for users & developers
